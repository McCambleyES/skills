Ten original two-tone icons on a 24px grid: 1.5px rounded strokes in one hue, with a 22% fill of the same hue on part of the shape. Colours are baked in (an `<img>` cannot take tokens), and each matches its `icon-*` token: Inbox blue, Issues violet, Cycles amber, Projects green, Roadmap teal, Insights pink, Triage orange, Integrations red, Teams indigo, Docs grey. Every hue holds 3:1 on both `bg-base` themes. Show them at 16px in dense UI and 20px in a `vx-icontile`. New icons follow the same grid, stroke and fill rule, and take a hue only if it names a new object type.
