Small status pieces: avatar, skeleton, progress, spinner and separator.

## Usage
- `sc-avatar` (32px; `--sm` 24px, `--lg` 40px) holds an `<img>` or initials on `muted`. Overlap several with `sc-avatar-group`.
- `sc-skeleton` is a pulsing `accent` block; size it with inline width and height to match what is loading.
- `sc-progress` with an inner `<span style="width:NN%">`; add `role="progressbar"` and the `aria-value*` attributes.
- `sc-spinner` on the `loader-circle` icon.
- `hr.sc-separator` for a horizontal rule; add `sc-separator--vertical` inside a flex row.
