Prose styles from shadcn's Typography page, for docs, articles and long descriptions.

## Usage
- `sc-h1` … `sc-h4`, `sc-p`, `sc-lead`, `sc-large`, `sc-small`, `sc-muted`, `sc-blockquote`, `sc-list`, `sc-code` (inline) and `sc-link`.
- `sc-h2` carries a bottom border and 40px of space above; `sc-p` spaces itself 24px from the previous paragraph.
- Use these in prose only. App UI text stays at 14px with labels, card titles and table headers doing the hierarchy.
