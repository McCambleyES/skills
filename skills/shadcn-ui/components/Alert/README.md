An inline callout, matching shadcn's `Alert`.

## Usage
- `sc-alert` with an optional leading 16px icon, then `sc-alert-title` and `sc-alert-description`.
- `sc-alert--destructive` turns the text and icon `destructive`. There is no success or warning variant by default; add a token pair if you need one (see README, Colour).
- Use `role="status"` for information and `role="alert"` for errors.
