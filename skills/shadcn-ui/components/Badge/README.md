A small pill for status and counts, matching shadcn's `Badge`.

## Usage
- `sc-badge` (primary), `sc-badge--secondary`, `sc-badge--destructive`, `sc-badge--outline`.
- Prefer `outline` or `secondary` for status in tables; reserve the filled default for counts and `destructive` for failures.
- A 12px icon may lead the label. On an `<a>`, it gains a hover state.
