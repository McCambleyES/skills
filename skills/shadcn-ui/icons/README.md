A starter set of Lucide icons, shadcn/ui's default icon library, copied unchanged from `lucide-static` 1.70.0 (ISC licence in `LICENSE`). 24px grid, 2px round strokes, `stroke="currentColor"`, so they take the colour of the surrounding text.

Inline them as `<svg>` (not `<img>`) so `currentColor` works, at 16px in buttons, menus, inputs and alerts. For an icon not here, copy it from lucide.dev or `https://cdn.jsdelivr.net/npm/lucide-static@1.70.0/icons/<name>.svg` and keep the same attributes.
