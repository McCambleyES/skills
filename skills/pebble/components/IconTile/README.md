A 40px rounded tile holding one icon, neutral or on a soft status tint.

## Usage
- `pb-icontile` around one 20px `pb-icon`. Neutral by default (`default` fill, `text-primary` icon); add `--accent`, `--success`, `--warning` or `--danger` for the soft tint with matching `*-soft-text` icon.
- Use it at the top of feature cards and in empty states. In lists, buttons and menus, use the bare icon instead.
- Pick the tone by meaning, not decoration: in a grid of feature cards, keep most tiles neutral or all one tone.
